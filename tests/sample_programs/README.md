# Sample Programs

This directory is for storing test programs to evaluate the obfuscation pipeline.

Provide simple, moderate, and sensitive/crypto-style C files to test different features of the `ProtectionPlanner` and `ThreatAnalyzer`.

Examples:
- `simple.c`: basic "Hello World" or simple arithmetic.
- `moderate.c`: nested loops, sorting algorithms.
- `crypto.c`: functions mimicking authentication checks, AES, or RSA implementations.
